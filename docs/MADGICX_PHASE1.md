# Madgicx-style Phase 1

## Production-safe workflow

Staff creates a draft -> AI assists with content -> staff saves -> staff submits for approval -> Admin reviews caption/media/platforms -> Admin approves, rejects, or requests changes -> only approved posts can enter publishing/scheduling.

## Stages

1. AI Caption Generator
2. Brand Voice presets
3. Caption Rewrite / Improve
4. Hashtag Suggestions
5. AI Post Ideas
6. Approval-center integration verification
7. Content calendar foundation
8. Analytics foundation

## Safety rules

- AI generation never publishes directly.
- Existing workplace, brand, account, and platform permissions remain authoritative.
- Approval is mandatory before publishing.
- AI API credentials must remain server-side.
- Each stage must pass typecheck/build before production deployment.
- Production deployment is intentionally deferred until the deployment window is available.
